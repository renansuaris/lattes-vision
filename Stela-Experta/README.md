# Referencias da Plataforma Stela Experta

Esta pasta preserva materiais publicos usados apenas como referencia de produto e pesquisa para o LattesVision. A interface e as funcionalidades proprietarias da Plataforma Stela Experta nao devem ser copiadas; os materiais servem para estudar formas de apresentar indicadores academicos, bibliometricos e comparativos.

## Ideias de produto para avaliar futuramente

- paineis quali-quantitativos com explicacao da fonte e cobertura;
- comparacao entre pesquisadores, grupos e programas;
- filtros temporais aplicados simultaneamente aos indicadores;
- detalhamento dos itens que formam cada grafico;
- exportacao de relatorios e dados consolidados;
- indicadores bibliometricos adicionais, sempre com fonte e metodologia explicitas.
